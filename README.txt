TECHSHOP - Web Programiranje

UPUTSTVO ZA POKRETANJE PROJEKTA

1. Pokrenuti XAMPP.

2. Pokrenuti Apache i MySQL.

3. Kopirati folder "TechShop" u:

C:\xampp\htdocs\

4. Otvoriti phpMyAdmin:

http://localhost/phpmyadmin

5. Kreirati bazu podataka pod nazivom:

techshop

6. Importovati fajl:

database/techshop.sql

7. Proveriti fajl:

config/config.php

Podešavanja baze su:

"DB_HOST", "localhost"
"DB_NAME", "techshop"
"DB_USER", "root"
"DB_PASSWORD", ""

8. Otvoriti projekat:

http://localhost/techshop/index.php
